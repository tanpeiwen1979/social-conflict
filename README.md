## 🎵 《拒绝伤害》

打架、冲突、暴力行为，带来伤害和悲伤；  
有害的威胁（名词），别用威胁（动词）添心伤。  
杀死生命、使丧失能力，受害者需要帮；  
丢失的笑容一起找回，友善带来力量。  
种族的偏见会使有偏见者歧视——不应该！  
尊重平等手牵手，让世界闪亮！
